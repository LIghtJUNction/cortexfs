# CortexFS

CortexFS 是一个面向 AI API 基础设施的 provider-neutral Linux FUSE 文件系统。
它把 API format、provider 实例、模型、请求、响应、thread、工具、记忆、审计和控制节点暴露为普通文件系统对象。

挂载树就是 ABI：

```text
/
  status
  cap/
  format/
  provider/
  model/
  home/
  tool/
  memory/
  audit/
  control/
```

## 快速开始

```bash
paru -S cortexfs-git
cortex status
```

本地挂载：

```bash
sudo mkdir -p /ctx
sudo chown "$USER:$USER" /ctx
cortex mount /ctx
export CTX_HOME="/ctx/home/$(id -u)"
```

提交文件 ABI 请求：

```bash
api="$CTX_HOME/api/openai.chat"

printf '%s\n' '{"messages":[{"role":"user","content":"Reply with cortexfs-ok"}]}' \
  > "$api/inbox/001.tmp"

mv "$api/inbox/001.tmp" "$api/inbox/001.req.json"
printf '1\n' > /ctx/control/drain

cat "$api/outbox/001.resp.json"
```

## 核心思想

CortexFS separates:

- `format/`：协议形状，例如 `openai.chat` 或 `anthropic.messages`。
- `provider/`：后端/账号实例，包括官方 API、中转站和本地运行时。
- `model/`：provider 作用域内的模型描述。
- `home/<uid>/route/`：用户可见的路由决策。
- `audit/`：请求、路由、策略、执行和导出的可观测性。

密钥不进入挂载树。文件系统只暴露 secret 状态和 active key id；真实 secret 值应由 `cortexd` 解析。
