# 文档与来源

本目录是 CortexFS 文档的 canonical 源。当前仓库保留规范、历史操作指南和
参考资源；产品实现、测试、示例、安装脚本与文档站点代码已移除。操作指南描述
源码快照 `v0.1.21`（`84f349c97bc2f6a611109686a02e21de3800042a`），不表示当前
仓库仍能执行其中的安装、构建或测试命令。

重建入口位于 [`cortexfs-prompts`](cortexfs-prompts/README.md) Git 子模块。它包含
以功能和外部行为为核心的提示词、随包提供的规范资料、提取证据与 SHA-256 清单。
提示词已生成，尚未通过独立重建验证。

## 规范优先级

`spec/` 中更具体的详细 ABI 文档优先于摘要、旧宣传文案和历史翻译。当前稳定根
条目为 `status`、`bin`、`model`、`agent`、`tool`、`channel`、`home`、`shared`。
若未来发现规范之间的冲突，应记录具体条目并修正文档，不要自行扩展 ABI。

简体中文译文存放在 `translations/zh-Hans/`，只保留与英文 canonical 文档不同的
真实翻译。文档站点生成器已从当前树移除。
